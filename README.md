# guangbo1314.github.io

使用 [VitePress](https://vitepress.dev) 搭建的个人网站 / 文档站点。

## 本地开发

```bash
npm install
npm run docs:dev
```

## 构建

```bash
npm run docs:build
npm run docs:preview
```

## 目录结构

```
docs/
├── .vitepress/config.mts   # 站点配置
├── index.md                # 首页
└── guide.md                # 示例文档
```

## 写作约定

- `# 标题` 表示大标题
- `[显示文字](链接)` 表示超链接
- 其余为普通文本
